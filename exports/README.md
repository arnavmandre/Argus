# Exported packages

- `UrbanTwin_Omniverse_Handoff.zip`: current complete teammate handoff. It includes
  documentation, integration tools, phases 1–8, and directly openable USD scenes.
- `phase8.zip`: older point-in-time Phase 8 archive retained for reference. The
  complete handoff archive and live repository are newer sources of truth.

The teammate-owned `Simulation/` directory is deliberately excluded to avoid
overwriting simulator work. Its current schema mismatch is documented in the
handoff guide.
